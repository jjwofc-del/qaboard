# QABoard v0.3.2 — 프로젝트 테스트 케이스 통계 일치

## 변경 사항
- Projects 목록의 테스트 케이스 수는 실제 프로젝트에 연결된 케이스만 표시합니다.
- Projects 화면의 Test cases KPI는 실제 연결된 케이스의 총합으로 계산합니다.
- Project 상세 화면에서 중복된 샘플 수치 대신 연결된 케이스 수만 표시합니다.
- Test Case 신규 생성 및 프로젝트 변경 직후, 프로젝트 집계는 저장 데이터 기반으로 갱신됩니다.
- 예전에 만든 프로젝트 미지정 테스트 케이스는 어떤 프로젝트에도 자동 연결하지 않습니다.
- 진행률(%)은 기존처럼 수동 설정 값입니다. 테스트 케이스 개수로 계산하지 않습니다.
- 기존 `localStorage` 키 `qaboard-demo` 유지, 데이터 초기화 없음.

## 테스트
1. Projects 목록과 상세 화면의 연결된 테스트 케이스 수가 일치하는지 확인합니다.
2. 프로젝트 A에 케이스를 추가하면 A의 숫자가 1 증가하는지 확인합니다.
3. A의 케이스를 프로젝트 B로 변경하면 A는 1 감소, B는 1 증가하는지 확인합니다.
4. 미지정 케이스는 프로젝트 집계에서 제외되는지 확인합니다.
5. 새로고침 후 수치가 유지되는지, 다른 메뉴가 정상인지 확인합니다.
