# QABoard v0.3.1 — Test Case ↔ Project 연결

기존 정적 GitHub Pages 데모(HTML, CSS, JavaScript)를 유지합니다.

## 이번에 추가한 기능
- Test Cases 목록에 프로젝트 열과 프로젝트별 필터
- 테스트 케이스 생성 시 프로젝트 선택(또는 미지정)
- Test Case 상세 보기에서 프로젝트 표시
- Edit test case에서 기존 프로젝트로 소속 변경 및 저장
- Project 상세 보기에서 실제 연결된 테스트 케이스 개수 표시
- 이전에 생성한 케이스는 **자동 연결하지 않고** 미지정 상태로 유지(데이터 오인 방지)
- localStorage 저장 키 `qaboard-demo` 유지(기존 데이터 마이그레이션 불필요)

## 범위
기존 프로젝트 화면의 `cases`는 샘플 통계치이며, 이번에 새로 만든 `실제 연결한 테스트 케이스`는 연결 관계를 정확히 집계한 숫자입니다. 샘플 통계치를 모두 연결 개수로 전환하는 작업은 별도 단계에서 진행합니다.

## GitHub 업로드
압축 해제 후 저장소 루트에 `index.html`, `README.md`, `src` 폴더를 업로드합니다. 기존 파일을 같은 경로로 교체하세요.

## 개인정보 안내
브라우저 localStorage에만 데모 데이터가 저장됩니다. 실제 개인정보나 고객 데이터는 입력하지 마세요. 실제 쇼핑몰과 연결되지는 않습니다.
